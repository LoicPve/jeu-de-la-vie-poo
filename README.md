# Jeu de la Vie — POO C++ & SFML

Implémentation du **Jeu de la Vie de Conway** réalisée en **C++** dans le cadre du module de Programmation Orientée Objet (CESI Lille — CPI A2).

## Architecture & Concepts POO
- Séparation stricte interface / implémentation (`.hpp` / `.cpp`)
- Modélisation orientée objet de la grille, des cellules et des règles d'évolution
- Diagrammes UML de conception disponibles dans `Diagrammes/`
- Interface graphique temps réel avec **SFML** (`GUI-SFML/`)

## Compilation & Exécution
```bash
make
```
